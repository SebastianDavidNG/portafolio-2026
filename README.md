# Portafolio 2026 — Sebastián Niño

Portafolio personal de **Sebastián David Niño G.**, desarrollador Full Stack.

Construido con **React + Vite**, con diseño moderno, responsive y animaciones CSS personalizadas.

## 🚀 Tecnologías

- **React 19** — Interfaz de usuario declarativa
- **Vite 8** — Bundler y servidor de desarrollo ultra-rápido
- **CSS Modules / Custom CSS** — Estilos modernos sin dependencias externas
- **ESLint** — Linting de código

## 📂 Estructura

```
src/
├── components/
│   ├── Header/     # Navegación sticky con menú hamburguesa
│   ├── Hero/       # Sección principal con nombre y CTA
│   ├── About/      # Información personal y estadísticas
│   ├── Skills/     # Habilidades técnicas con barras de progreso
│   ├── Projects/   # Proyectos destacados con links
│   ├── Contact/    # Formulario de contacto e información
│   └── Footer/     # Pie de página con navegación
├── App.jsx
├── App.css
├── index.css       # Variables CSS y estilos globales
└── main.jsx
```

## 🛠️ Desarrollo

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build de producción
npm run build

# Vista previa del build
npm run preview

# Lint
npm run lint
```

## 📋 Secciones

- **Header** — Navegación sticky con scroll suave y menú responsive
- **Hero** — Presentación con nombre, título, CTA y redes sociales
- **Sobre mí** — Bio, estadísticas y botones de acción
- **Habilidades** — Frontend, Backend, Bases de datos y Herramientas
- **Proyectos** — 6 proyectos con tags, links a código y demo
- **Contacto** — Formulario de contacto + información de contacto
- **Footer** — Navegación, redes y créditos
